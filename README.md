# Ближе ко Христу 🌿

**Бесплатный евангельский молитвослов** для чтения на телефоне и компьютере. Простое место для личной молитвы, чтения Священного Писания и применения веры в повседневной жизни.

Приложение рассчитано на русскоязычных христиан протестантской (евангельской) традиции, но открыто для всех желающих.

## Что уже работает

- **19 жизненных ситуаций**: тревога, семья, отношения, дети, долги, работа, болезнь, сомнения и другие.
- **30 дней с Евангелием**: отрывок для чтения, размышление, авторская молитва и конкретное действие.
- **Поиск, категории, избранное** и прямая ссылка на отдельную молитву.
- **Личный дневник**, отметки пройденных дней, резервная копия и восстановление JSON, экспорт текста.
- **Мобильная версия и установка как приложение (PWA)**, частичная офлайн-работа после первой загрузки.
- Без регистрации, рекламы, аналитики, сервера, подписок и внешних библиотек.

> Молитвы составлены авторами проекта на основании библейских тем. Это не дословные цитаты из Библии и не обещание обязательного исполнения просьб. Читайте указанные отрывки в полном контексте и в предпочитаемом переводе.

## Быстрый локальный запуск

Нужен только современный браузер и Python 3 **или** любой локальный статический сервер:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Для работы модулей JavaScript **не открывайте `index.html` как `file://`**. Сборка, npm-зависимости и серверная база данных не нужны.

### Тесты

Требуется Node.js 20+; внешние пакеты не устанавливаются:

```bash
npm test
```

## Подготовлено к GitHub Pages (публикация только вручную)

Исходники уже опубликованы в репозитории [fishand1982/blizhe-ko-hristu](https://github.com/fishand1982/blizhe-ko-hristu). Сам сайт публикуется **отдельно и только вручную** после проверки содержания.

1. Проверьте результат проверок на вкладке **Actions → Check content and syntax**.
2. Проведите богословскую и редакционную вычитку, проверьте приложение на реальных телефонах.
3. В **Settings → Pages → Build and deployment** установите **Source: GitHub Actions**.
4. В **Actions → Publish to GitHub Pages** выберите **Run workflow**.
5. После успешной публикации адрес: https://fishand1982.github.io/blizhe-ko-hristu/
6. Проверьте дневник, импорт и экспорт резервной копии, офлайн-режим и установку PWA.

Поскольку пути к файлам относительные, приложение работает и по адресу `/`, и во вложенной папке репозитория. Изменять `base` и запускать сборщик не требуется.

### С первого релиза важно

- Проверьте библейские ссылки и формулировки с редактором/пастором своей общины, если претендуете на официальный статус общинного издания.
- Проверьте орфографию, работу дневника и импорт/экспорт на реальных устройствах.
- Не добавляйте в репозиторий личные молитвы пользователей или чужие персональные сведения.
- Приложение создано без API-ключей; секретов в этом проекте нет.
- Если пользователь раньше открывал сайт локально, записи не переходят на новый домен автоматически: сначала выгрузите JSON, затем восстановите его на опубликованной версии.

## Использование и защита данных

Дневник, избранное и прогресс находятся в `localStorage` **на устройстве пользователя**. Они не синхронизируются между телефонами и могут исчезнуть после очистки браузера. Резервная копия JSON позволяет перенести их самостоятельно.

Приложение не заменяет медицинскую, психологическую, юридическую помощь или срочные меры безопасности. Подробно: [PRIVACY.md](PRIVACY.md) и [CONTENT_GUIDELINES.md](CONTENT_GUIDELINES.md).
