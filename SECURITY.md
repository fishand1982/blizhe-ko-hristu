# Безопасность

В проекте нет собственного сервера, аккаунтов или API-ключей. Личные записи хранятся в браузере пользователя.

Сообщайте об обнаруженных уязвимостях конфиденциально через механизм **GitHub Private Vulnerability Reporting**, если он включён в настройках репозитория. Если функция ещё не настроена, не публикуйте в открытом Issue личные данные или эксплойты.

Перед публичным запуском включите в настройках репозитория Private Vulnerability Reporting и просмотрите зависимости/добавленный код. В текущей версии сторонних runtime-зависимостей нет.
