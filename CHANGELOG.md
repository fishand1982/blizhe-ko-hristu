# История изменений

## v1.0.1 — 2026-11-04

- Исправлена стратегия офлайн-кеша: только файлы приложения, без случайных запросов и подмены недоступного JS HTML-страницей.
- Добавлена обложка соцсетей PNG, совместимая с распространёнными сервисами предпросмотра.
- Дополнительные регрессионные тесты и руководство по запуску под GitHub `fishand1982`.

## v1.0.0 — 2026-11-04 (предрелиз)

- Первый открытый прототип в мягком природном стиле.
- 19 молитв для жизненных ситуаций с библейскими ссылками.
- 30-дневный план чтения Евангелия.
- Локальный молитвенный дневник и резервные копии.
- Адаптивный интерфейс, установка PWA, офлайн-кеширование.
- Подготовка к ручной публикации через GitHub Actions.
