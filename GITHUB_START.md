# Развёртывание «Ближе ко Христу»

Репозиторий: https://github.com/fishand1982/blizhe-ko-hristu

## Подготовка
- Убедитесь, что все файлы релиза загружены в корень репозитория.
- Дождитесь успешного workflow **Check content and syntax**.
- Проведите редакционную и богословскую вычитку молитв, убедитесь в корректности ссылок.
- Протестируйте приложение на реальных Android и iPhone.

## Публикация (только вручную)
1. GitHub → **Settings → Pages**.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. GitHub → **Actions → Publish to GitHub Pages → Run workflow**.
4. После успешного выполнения сайт будет доступен на https://fishand1982.github.io/blizhe-ko-hristu/

Workflow не публикует сайт на каждый push: нужен ручной запуск.

## Приватность
Исходники публичны; заметки и дневник каждого пользователя хранятся только в его браузере. Не коммитьте личные записи и резервные копии.
