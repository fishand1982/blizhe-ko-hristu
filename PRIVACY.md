# Конфиденциальность

Версия: 1.0, 4 ноября 2026 года.

«Ближе ко Христу» — статическое приложение без собственного сервера, регистрации, рекламы, аналитических инструментов и интеграций с внешними системами.

## Какие данные сохраняются

Если пользователь пользуется дневником, приложение сохраняет **только в его браузере** (`localStorage`):

- личную молитву;
- заметки к дням чтения;
- список избранных молитв;
- отметки о прохождении дней.

Приложение **не отправляет эти записи разработчику** и не содержит сетевого кода для их передачи. Резервная копия JSON или текстовый файл скачивается на устройство по инициативе пользователя. Если пользователь самостоятельно отправит файл третьему лицу, это выходит за пределы приложения.

## Хранение и удаление

Данные сохраняются до очистки данных браузера, смены устройства или до нажатия пользователем кнопки «Удалить мои записи» с подтверждением. Они не переносятся автоматически на другие домены или устройства. Рекомендуется периодически создавать резервную копию.

## Сетевые обращения

При посещении опубликованного сайта браузер загружает обычные статические файлы (`HTML`, `CSS`, `JavaScript`, изображения) с площадки размещения — например GitHub Pages. Провайдер хостинга технически может вести собственные серверные журналы, управляемые его правилами. Приложение не встраивает сторонние шрифты, трекеры, рекламу или запросы к сторонним API.

Service worker хранит копии статических файлов для офлайн-доступа, **не копирует содержимое личного дневника**.

## Важные ограничения

Это независимый некоммерческий молитвослов. Молитвы не заменяют медицинскую помощь, кризисную поддержку и защиту от насилия. Если кто-то находится в непосредственной опасности, следует обратиться в местные экстренные службы.
