# Как помочь проекту

Спасибо за желание сделать молитвослов полезнее. Проект свободный и открыт для исправлений.

## Предложить изменение

1. Откройте GitHub Issue с описанием идеи, ошибки или неточной библейской ссылки.
2. Для исправления кода создайте отдельную ветку и Pull Request.
3. Проверяйте изменения командой `npm test`.
4. Если исправляете молитву или размышление, поясните богословский смысл и укажите ссылки на Священное Писание.
5. Не добавляйте коммерческих изображений, текстов защищённых авторским правом переводов Библии и чужих молитв без разрешения.

## Принципы общения

Уважение, доброжелательность и честность. Дискуссии о толкованиях Писания допустимы, но нападки на людей и конфессии — нет.

## Персональные сведения

Никогда не прикладывайте в Issue или Pull Request реальные записи личного дневника, имена, контакты, диагнозы и другие личные данные без явного разрешения соответствующих людей.
